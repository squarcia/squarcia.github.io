02 — selected work

Tasks a reward function cannot express

Neuro-symbolic reinforcement learning for a legged robot

Imperial College London · SPIKE Group, led by Prof. Alessandra Russo

Standard reinforcement learning assumes the best next action depends only on the current state. Plenty of useful robot tasks break that assumption: visit A, then B, and never enter C along the way. A robot standing in exactly the same spot should behave differently depending on where it has already been — and a plain reward function has nowhere to keep that history.

I developed a neuro-symbolic algorithm that encodes this kind of temporally extended, non-Markovian task as an explicit symbolic machine the agent reasons over while it learns, and trained a Unitree Go2 Pro quadruped against it in the NVIDIA Isaac Simulator: environment modelling, reward specification, training, policy evaluation, then sim-to-real transfer onto the physical robot with quantitative validation of the gap. It extends the direction of my MSc thesis, Reward Machines for Real World Navigation.

Collaboration with University of Cardiff, University of Brescia and UCLA · funded by DEVCOM Army Research Laboratory
